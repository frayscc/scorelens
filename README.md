# ScoreLens

面向中学班主任的本地化学生成绩分析工具。数据只在浏览器本地处理，不上传服务器。

## 开发

```bash
npm install
npm run dev
npm test
npm run build
```

构建产物为 `dist/ScoreLens.html`，可以单独复制并通过 `file://` 直接打开。

## 班级与成绩导入

- 班级管理页可以新建、进入、删除班级或导入 `.scorelens` 备份。班级内的「退出班级」返回列表，考试与学生记录保存在当前浏览器中。
- 在班级内的「设置」可以修改班级名称和导出备份。导入与本地班级 ID 相同的备份时，需要确认覆盖。
- 成绩表中的「校次」按年级排名识别。单独的「校次」对应总排名，「语文校次」等带学科名称的列对应学科排名。字段映射每行可直接点击「忽略」，也可用下拉菜单恢复映射。
